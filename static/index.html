SmartScaler
Was passiert hier? Die STL-Datei wird vom Browser eingelesen und an den lokalen Flask-Server (app.py) gesendet. Der Server speichert die Datei unter einem eindeutigen Job-ID-Namen im uploads/ Ordner. Gleichzeitig wird ein Job-Objekt erstellt und ein Background-Thread gestartet, der die Inferenz asynchron ausführt.

Technische Details
· Protokoll: HTTP POST multipart/form-data
· Job-ID: UUID (8 Zeichen)
· Format: Binär-STL oder ASCII-STL
· Three.js parst die STL direkt im Browser für die 3D-Vorschau
Was passiert hier? Das Modell mesh-to-cadquery-qwen (Qwen2-1.5B + FourierPointEncoder) wird auf die GPU geladen. Die STL wird in eine Punktwolke mit 256 Punkten konvertiert (Farthest Point Sampling). Anschließend werden 10 Kandidaten generiert — jedes Mal mit einem anderen FPS-Sample, damit die Ausgaben variieren.

Architektur
· Base LLM: Qwen2-1.5B
· Point Encoder: FourierPointEncoder(51→1536)
· Fourier-Frequenzen: 2⁰ bis 2⁷ (8 Frequenzen)
· Input: [pad]×256 + [im_start]
· max_new_tokens: 768
· Selektion: niedrigste Chamfer Distance
Was passiert hier? Das Modell gibt normalisierte Koordinaten im Bereich [-100, 100] aus — die echten Maße sind unbekannt. Der SmartScaler vergleicht die Bounding-Box-Ausdehnungen der originalen und generierten STL und berechnet einen Korrekturfaktor pro Achse.

Formel
scale_x = orig_extent_x / gen_extent_x
scale_y = orig_extent_y / gen_extent_y
scale_z = orig_extent_z / gen_extent_z

Rescaling-Methode
· LLM (LM Studio): reschreibt alle Zahlenwerte im CadQuery-Code
· Regex-Fallback: multipliziert alle Zahlen mit dem uniformen Faktor
